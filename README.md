# Employee-Workforce-Analysis-Excel-Claude-AI-ChatGPT
### Project Overview
This project focuses on analyzing employee workforce data using Microsoft Excel with AI-assisted analysis through Claude AI and ChatGPT.  ChatGPT was used to create and refine analytical prompts, while Claude AI was used to assist with data cleaning, KPI generation, trend analysis, insights, and chart recommendations.
ChatGPT was used to create and refine analytical prompts, while Claude AI was used to assist with data cleaning, KPI generation, trend analysis, insights, and chart recommendations. The final analysis and dashboard were prepared in Excel.

### Objective
The objective of this project was to transform raw employee workforce data into a structured and easy-to-understand Excel dashboard that provides insights into workforce distribution, trends, city-wise analysis, and gender-wise analysis.
### Tools Used
Microsoft Excel
Claude AI
ChatGPT
### Project Workflow
### Project Workflow

Raw Employee Dataset → ChatGPT Prompt Creation → Claude AI Data Cleaning → KPI & Trend Analysis → City & Gender Analysis → Excel Dashboard

###  Data Preparation

The dataset was first reviewed for data-quality issues such as:

Missing values
Duplicate records
Inconsistent values
Data-format issues
Incorrect or inconsistent categories

Claude AI was used to assist with identifying and preparing the required cleaning steps.

### KPI & Analysis

The cleaned dataset was used to generate relevant workforce KPIs and analytical summaries.

### The analysis includes:

Workforce KPIs
Workforce trends
City-wise workforce analysis
Gender-wise workforce analysis
Top and bottom city analysis
Chart-ready summaries
Business insights

Only metrics supported by the available dataset were used.

### AI-Assisted Prompting

ChatGPT was used to create and refine prompts for the analysis workflow.

### Claude AI was then used to assist with:

Data cleaning
KPI generation
Trend identification
Insight generation
City-wise and gender-wise analysis
Chart recommendations
Excel dashboard preparation

The generated outputs were reviewed and organized in Excel before creating the final dashboard.

### Excel Dashboard

The final Excel dashboard, Employee Workforce, presents the key workforce metrics and visual analysis in a single view.

### The dashboard includes:

KPI section
Dropdown/filter controls
Workforce charts
City-wise analysis
Gender analysis
Top/bottom analysis
Data labels and visual summaries
Key Learning

## This project demonstrates how AI tools can support an analytics workflow by helping with data-quality checks, KPI identification, insight generation, and dashboard planning, while Excel is used for the final analysis and visualization.
